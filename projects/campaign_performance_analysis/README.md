# Campaign Performance Analysis

## Objective

Identify the highest-performing marketing channels.

## Dataset

Digital Marketing Campaign Dataset

## Business Questions

- Which channels drive the highest conversion rate?
- Which channels generate the most revenue?
- Which channels should receive additional budget?

## SQL Concepts Used

- GROUP BY
- CASE WHEN
- HAVING
- Window Functions

## Key Findings

- Email had the highest conversion rate.
- Social generated the highest volume.
- Search had the best cost efficiency.

## Recommendation

Increase investment in Email and Search campaigns.
